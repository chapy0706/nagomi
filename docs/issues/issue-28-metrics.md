# issue-28: 利用状況のメトリクス収集（Vercel Analytics等）

## 概要・背景・目的

サービスの利用傾向を把握するため、アクセス解析・パフォーマンス計測を導入する。
Vercel Analytics の無料枠で十分な範囲を、個人を追跡しない形で導入する。

メトリクスは「サービスを良くする」ためのものであり、「ユーザーを監視する」ためのものではない。
この境界を、設定とドキュメントで明確に分ける。

## 受け入れ条件

- [ ] Vercel Analytics が有効化されている
- [ ] ページビュー・主要操作のイベントが計測されている
- [ ] パフォーマンスメトリクス（Core Web Vitals）が取得されている
- [ ] 個人を追跡可能な情報（社員ID、認証情報）はイベントペイロードに含まれない
- [ ] DNT（Do Not Track）ヘッダーが尊重される
- [ ] プライバシーポリシーにメトリクス取得が明記されている
- [ ] 計測内容と取得しない情報がドキュメント化されている
- [ ] `make verify` がエラーを発生させない

## 技術的な検討事項

- Vercel Analytics は無料枠で月2,500イベント程度。50人規模なら十分
- カスタムイベントは「機能の利用回数」レベルに留める（ユーザー単位の追跡はしない）
- セッション識別子は使わない（cookie レス）
- ヒートマップ・録画系の機能は導入しない
- 数値は集計値として管理者ダッシュボードに反映する選択肢もあり
