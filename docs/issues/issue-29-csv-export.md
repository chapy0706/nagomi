# issue-29: 管理画面からのCSVエクスポート機能

## 概要・背景・目的

管理者がデータをローカル分析・社内報告に活用できるよう、ダッシュボードの集計データをCSVで書き出せるようにする。
将来対応扱いの issue。MVP 運用開始後、需要が確認できてから着手する。

エクスポート対象は集計データに限定し、個別ユーザーの利用ログは出力しない。
プライバシー保護の原則を、エクスポート機能にも適用する。

## 受け入れ条件

- [ ] 管理者ダッシュボードに「CSVダウンロード」ボタンが設置されている
- [ ] エクスポート対象は以下に限定される
  - 日次・週次のアクティブ人数
  - 時間帯別の利用傾向
  - 通話発生数の推移
  - トピック別の通話比率
  - 通報の集計（カテゴリ別件数）
  - 満足度集計
- [ ] 個別ユーザーの利用ログはエクスポート対象に含まれない
- [ ] CSVは UTF-8 with BOM 形式（Excel で文字化けしない）
- [ ] エクスポート操作自体がログに残る（管理者の操作の透明性）
- [ ] エクスポート可能な期間を限定する（例: 直近1年のみ）
- [ ] `make verify` がエラーを発生させない

## 技術的な検討事項

- CSV生成は Edge Function 側で行う（クライアント側で大量データを扱わない）
- ファイル名規則: `nagomi-{type}-{from}-{to}.csv`
- 列ヘッダーは日本語で出力（ビジネスユーザー向け）
- 日付フォーマットは ISO 8601（YYYY-MM-DD HH:mm:ss）
- 数値列にはカンマ区切りは入れない（再集計しやすさを優先）
- 文字エスケープを徹底（カンマ・改行・ダブルクォート）
